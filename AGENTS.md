# Repository Guidance

This is a public-shareable household planning project. Never commit personal names, home addresses, employer-confidential data, exact account balances, loan identifiers, resume contact details, credentials, or exported private plan files.

Treat `../wil-bud` and `../mdw-jobs` as read-only references. Summarize only the minimum necessary planning constraints. Current prices, rates, taxes, job openings, permits, and programs must be dated and sourced.

The dependency-free site lives in `landing-page/`. Keep it usable below a GitHub project path by using relative URLs. Run the focused checks in `scripts/check.sh` before delivery.
